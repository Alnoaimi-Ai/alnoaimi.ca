# alnoaimi.ca

This repository contains the static website for alnoaimi.ca and the Excalibur agent guidance.

## Website
The site is a lightweight static landing page designed to be deployed on GitHub Pages or any static hosting provider.

## Files
- `index.html` — homepage markup
- `styles.css` — styling and layout
- `script.js` — small frontend behavior
- `EXCALIBUR_AGENT_INSTRUCTIONS.md` — developer-focused agent instructions for Excalibur

## GitHub Pages deployment
1. Push this repository to GitHub.
2. Go to the repository settings.
3. Open Pages.
4. Select "Deploy from a branch".
5. Choose `main` and `/root`.
6. Save and wait for the site to publish.

## Excalibur agent
The agent should be created in Copilot Studio with the instructions from `EXCALIBUR_AGENT_INSTRUCTIONS.md`.

## Notes
This is the first version of the project and is intentionally simple, fast, and easy to extend.
